ABOUT THE PROJECT

Home Loan Eligibility Prediction Using Machine Learning

This college project demonstrates an end-to-end classification workflow that predicts whether a home-loan application is likely to be approved based on applicant and loan attributes.

PROJECT OBJECTIVE

Turn Loan Data into a Prediction

The model uses the loan dataset supplied with this project and predicts the Loan_Status target. The web form sends applicant information to a local Python Flask backend.

The current dataset file contains 5 sample records. Because of this, the present version should be treated as a demonstration of the ML pipeline rather than a reliable real-world banking model.
